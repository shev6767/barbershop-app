# Барбершоп: журнал записей

Учебный проект по дисциплине «Практика создания веб-приложений».

Приложение для администратора барбершопа: запись клиентов к мастерам, список и поиск записей, расписание на день и статистика по выручке.

Описание проекта, полей и страниц: [docs/project-spec.md](docs/project-spec.md)

## Стек

React, TypeScript, Vite, React Router

## Страницы

| Адрес | Страница |
|-------|----------|
| / | Главная (журнал записей на сегодня) |
| /appointments | Список записей |
| /appointments/:id | Карточка записи |
| /appointments/new | Новая запись |
| /appointments/:id/edit | Редактирование записи |
| /schedule | Расписание мастеров |
| /stats | Статистика |
| любой другой адрес | Страница не найдена |

## Запуск

```
npm install
npm run dev
```

Сборка:

```
npm run build
```
