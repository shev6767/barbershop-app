# ЛР2. Главная страница

Проект: «Барбершоп: журнал записей». Ветка: `lab-2`.

## Цель главной страницы

Главная показывает администратору, что происходит сегодня: сколько записей на день, сколько клиентов еще ждем, сколько уже обслужили и какая выручка. Ниже таблица записей на сегодня и карточка следующего клиента.

## Верстка

- шапка с названием «Барбершоп» и меню (пока работает только «Главная», остальные разделы будут в ЛР3);
- заголовок «Журнал записей», описание и сегодняшняя дата;
- 4 карточки со сводкой;
- таблица записей на сегодня, статус показан цветной меткой;
- справа карточка «Следующий клиент» с телефоном и пожеланием;
- на узком экране карточки встают по 2 в ряд, а таблица и следующий клиент друг под другом.

## Mock-данные

`src/mocks/appointments.ts` - массив из 12 записей (7 на сегодня, остальные на соседние дни). Поля: id, clientName, phone, comment, service, master, status, price, date, isPaid. Тип описан в `src/types.ts`.

`src/mocks/api.ts` - функция `getAppointmentsMock()`, возвращает Promise и отдает копию массива через 800 мс, как будто данные пришли с сервера.

## Компоненты

- `Header` - шапка и меню;
- `HomePage` (pages) - страница, загружает данные и считает сводку;
- `StatsCards` - 4 карточки, получает числа через props;
- `AppointmentsTable` - таблица записей, получает массив через props;
- `StatusBadge` - цветная метка статуса;
- `NextClient` - карточка следующего клиента.

## useState

В `HomePage`: `appointments` - записи, которые пришли из mock-функции, `isLoading` - идет ли загрузка.

## useEffect

В `HomePage` с пустым массивом зависимостей: при открытии страницы один раз вызывается `getAppointmentsMock()`, после ответа данные кладутся в `appointments`, а `isLoading` становится false. Пока данные не пришли, показывается «Загрузка...».
