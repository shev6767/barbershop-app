# Барбершоп: журнал записей

## Пользователь и проблема

Приложением пользуется администратор небольшого барбершопа (2-3 мастера). Сейчас записи клиентов ведутся в тетрадке или в переписке, из-за этого бывают накладки по времени, забытые записи и непонятно, сколько заработали за неделю.

Приложение нужно, чтобы:
- хранить все записи клиентов в одном месте;
- быстро находить запись по имени клиента или телефону;
- видеть, кто к какому мастеру записан на сегодня;
- отмечать, что клиент пришел и оплатил;
- смотреть простую статистику по выручке и услугам.

## Основная сущность: запись (Appointment)

| Поле | Тип | Описание |
|------|-----|----------|
| id | string | уникальный номер записи |
| clientName | string | имя клиента |
| phone | string | телефон клиента |
| comment | string (многострочный) | пожелания клиента, например «коротко по бокам, сверху оставить» |
| service | string (категория) | услуга: мужская стрижка, детская стрижка, стрижка бороды, стрижка + борода, бритье |
| master | string | мастер, к которому записан клиент |
| status | string | статус: записан, выполнено, отменено, не пришел |
| price | number | стоимость услуги в рублях |
| date | string | дата и время записи |
| isPaid | boolean | оплачена ли услуга |

## Страницы

| URL | Страница | Что показывает | Действия пользователя |
|-----|----------|----------------|-----------------------|
| / | Главная (Dashboard) | записи на сегодня, количество записей, выручка за день, ближайший клиент | перейти к списку, создать запись |
| /appointments | Список записей | все записи в виде таблицы | поиск по имени и телефону, фильтр по мастеру, услуге и статусу, сортировка по дате и цене |
| /appointments/:id | Карточка записи | все поля одной записи | изменить статус, отметить оплату, перейти к редактированию, удалить |
| /appointments/new, /appointments/:id/edit | Создание и редактирование | форма записи | заполнить поля, проверить ошибки, сохранить или отменить |
| /stats | Статистика | выручка по дням, популярные услуги, загрузка мастеров, процент отмен | выбрать период |
| /schedule | Расписание мастеров | сетка на день: мастера и занятое время | выбрать дату, увидеть свободные окна, записать клиента на свободное время |

## Действия с записью

- создать новую запись;
- посмотреть подробную информацию;
- изменить данные записи;
- удалить запись;
- поменять статус (записан, выполнено, отменено, не пришел);
- отметить оплату;
- найти запись, отфильтровать и отсортировать список;
- импортировать записи из JSON-файла.

## Пользовательские сценарии

1. **Новая запись по телефону.** Клиент звонит, администратор открывает «Расписание», выбирает дату, видит свободное окно у мастера, нажимает на него и попадает в форму. Заполняет имя, телефон, услугу, сохраняет. Запись появляется в списке и в расписании.
2. **Клиент пришел.** Администратор на главной видит ближайшую запись, открывает ее карточку, после стрижки меняет статус на «выполнено» и ставит отметку «оплачено». Выручка за день на главной увеличивается.
3. **Клиент перенес время.** Администратор находит запись через поиск по телефону, открывает редактирование, меняет дату и время, сохраняет. Если время уже занято у этого мастера, форма показывает ошибку.
4. **Отмена записи.** Клиент пишет, что не придет. Администратор находит запись в списке, ставит статус «отменено». Время в расписании освобождается.
5. **Итоги недели.** В конце недели владелец открывает «Статистику», выбирает период и смотрит выручку, сколько было клиентов у каждого мастера, какая услуга самая популярная и сколько было отмен.

## Что не входит в первую версию

- онлайн-запись самими клиентами через сайт;
- авторизация и роли (мастер, администратор, владелец);
- SMS и напоминания клиентам;
- онлайн-оплата;
- настоящий сервер и база данных (пока mock-данные и localStorage);
- учет расходных материалов и зарплаты мастеров.
